## Инструкция по запуску

1. Клонировать репозиторий или распаковать архив проекта:
```bash
git clone https://github.com/rebys4/NIS_REACT_Diasamidze.git 
cd movies-react-ts
```

2.	Установить зависимости:
```bash
npm install
```

3.	Запустить проект:
```bash
npm run dev
```

4. Обоснование доработки на 9

Выполнено:
1)	Адаптивный дизайн — карточки фильмов перестраиваются в зависимости от ширины экрана (Grid с auto-fill + minmax).
2)	Реактивный поиск — реализован поиск через useRef (по условию задания) с динамической фильтрацией.
3)	Прокручиваемый список — при большом количестве фильмов контейнер аккуратно прокручивается, не обрезая контент.
