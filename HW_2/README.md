## Инструкция по запуску

1. Клонировать репозиторий или распаковать архив проекта:

```bash
git clone https://github.com/rebys4/NIS_REACT_Diasamidze.git
cd movies-react-ts
```

2. Установить зависимости:

```bash
npm install
```

3. Запустить проект:

```bash
npm run dev
```
